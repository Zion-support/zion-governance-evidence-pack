# Governance Evidence Pack

**Implementation status:** documented concept with a blank, manually completed worksheet and a static English information page. This is not an automated AI application or a verified production integration.

Use this repository to organize evidence references, review gaps and accountable decisions for a human-led governance review. It does not collect evidence, access other applications, assemble files, run AI inference or certify compliance.

## What is included

- [`templates/evidence-register.md`](templates/evidence-register.md) — manual governance evidence register; all review fields start blank or not assessed.
- [`NETWORK.md`](NETWORK.md) — relevant, reciprocal source-document links and a manual handoff path.
- `index.html` — static information and navigation; no forms, uploads, application storage or workflow execution.

## Try a reversible manual review

1. Copy the blank worksheet to an approved private workspace. Do not put customer records, credentials or completed evidence in this public repository.
2. Choose one bounded use case, name an accountable owner and record the scope and evidence limitations.
3. Complete the worksheet manually. Unknown or missing evidence remains unknown, not a passing result.
4. Have a qualified human reviewer examine the findings and decide whether to stop, request evidence or propose a separately approved pilot.
5. Keep any completed record private and use the related worksheet only through an explicit, authorized manual handoff.

**Stop rule:** do not approve a deployment when the owner, permitted data use or required review is unresolved. These worksheets do not replace legal, security, compliance or other professional review. No numeric score or checklist constitutes approval.

## Preview the static page

From the repository directory, run `python3 -m http.server 8000` and open `http://localhost:8000/`. This previews source locally; it is not evidence of a public deployment. The shared stylesheet is requested from the Zion website.
